# File Handling Management System Using Python

A menu-driven console application in Python that performs common file operations.

**Submitted by:** Shahul M
**Institute:** Besant Technologies
**Submitted to:** Ms. Gauthami

## Features
1. Create a new file
2. Write content to a file (overwrite)
3. Append content to a file
4. Read a file
5. Show file information
6. Search a word in a file
7. Copy a file
8. Rename a file
9. Delete a file
0. Exit

## How to run
python file_manager.py

## Concepts used
File handling, functions, loops, dictionary, exception handling, os, shutil and datetime modules
